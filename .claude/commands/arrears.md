Run `npm run rates -- arrears --json` (add `--min-days=N` to narrow). Show assessment, ratepayer, overdue, days, last step and next step. Total the overdue. For each next step, offer the draft: `npm run rates -- draft-letter <unit> --kind=reminder|final|mortgagee`.
