---
description: List the rating units on the roll, with value, ratepayer, this year's rates and balance.
---

Run `npm run rates -- units --json`. Add `--category=RES|COM|IND|RUR|LIF`, `--locality=<name>` or `--arrears` when the operator narrows it. Show a table: assessment, address, category, capital value, ratepayer, rates this year, balance. Call out any unit with no ratepayer on file or not assessed this year.
