---
description: Record an objection to the rating information database (s 29) or decide one.
---

New: `npm run rates -- object "<unit>" --objector="<name>" --grounds="..." --actor="<name>"`.
Decide: `npm run rates -- object-decide <id> upheld|dismissed|withdrawn --outcome="..." --actor="<name>"`. If upheld, correct the record (revalue, transfer, or /customise for a category change) and say which.
