description: Check the records against the Local Government (Rating) Act 2002 and related rules, each finding cited.

1. Run `npm run rates -- compliance --json`.
2. Report a table: level, rule, subject, finding. Breaches first, then actions, warnings and watch items.
3. For each breach, say the fix and the command for it. Draft any letter to drafts/, never send.
4. docs/compliance.md cites every rule. If a rule there looks out of date, say so and stop: the operator confirms the law, then you update the doc and the check together.

A clean list is not legal advice.
